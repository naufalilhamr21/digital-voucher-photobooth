# Alineas Studio — Design Direction (DESIGN.md)

## 1. Brand Identity & Personality
- **Brand:** Alineas Studio
- **Product:** Digital Photobooth Voucher System
- **Character:** Clean, editorial, high-end photography studio. Confident, modern, high contrast, distraction-free.
- **Mood:** Professional, responsive, and reliable in real-world event venue conditions (bright sun or low-light ballroom).

## 2. Color System
- **Base Surfaces:**
  - Pure White (`#FFFFFF`) for primary cards and QR code backgrounds
  - Studio Slate Light (`#F8FAFC`, `#F1F5F9`) for page backgrounds
  - Crisp Borders (`#E2E8F0`)
- **Dark Neutral Text:**
  - Headline Onyx (`#0F172A`)
  - Body Slate (`#334155`, `#475569`)
  - Subdued / Meta (`#64748B`)
- **Alineas Accent (Brand Red):**
  - Primary Red (`#DC2626`)
  - Bright Red Accent (`#EF4444`)
  - Deep Red Active/Hover (`#B91C1C`)
- **Functional Status Tints:**
  - Success Green: (`#16A34A` / `#22C55E`)
  - Warning / Buffer Amber: (`#D97706`)
  - Danger / Error Red: (`#DC2626`)

## 3. Typography
- **Primary Sans (UI):** Inter, system-ui, -apple-system, sans-serif
- **Monospace (Tokens & Timers):** JetBrains Mono, Roboto Mono, ui-monospace, monospace (high legibility for 6-character tokens e.g. `T9K2WP` and digital clocks)

## 4. Dials (antislop)
- **ENERGY:** 2 (Focused studio aesthetic, intentional accent placement)
- **RHYTHM:** 2 (Clean editorial rhythm, structured hierarchy)
- **MOTION:** 2 (Purposeful micro-interactions, smooth status alerts, spring feedback)
